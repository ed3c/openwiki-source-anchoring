# Evaluation Dependency License Policy

The core evaluation contract must remain usable with repository code and standard runtimes only.

For optional third-party tooling:

1. prefer MIT, Apache-2.0, BSD-2-Clause, or BSD-3-Clause;
2. record the exact version or commit, license, telemetry behavior, provider dependency, and removal path;
3. review transitive dependencies before redistribution or commercial deployment;
4. keep raw results in the neutral repository schema so a tool can be replaced;
5. do not describe source-available or fair-code licenses as permissive open source;
6. document any copyleft, hosted-service, trademark, model, or dataset terms separately.

A permissive software license does not automatically grant rights to source repositories, datasets, prompts, model outputs, or third-party documentation used in an evaluation. Record those rights at the artifact level.
