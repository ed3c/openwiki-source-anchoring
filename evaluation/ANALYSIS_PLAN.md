# Minimum Analysis Plan

For each frozen task, preserve paired outcomes for every documentation candidate.

Report:

1. raw counts and per-item transitions;
2. results by repository and independent generation run;
3. cluster-aware uncertainty using repository-generation runs as clusters;
4. repeated answerer and judge variance;
5. human/judge per-criterion agreement;
6. token, latency, cost, and document-size tradeoffs;
7. failures and correct abstentions, not only PASS totals.

Use an equivalence claim only with a preregistered practical margin and repeated data. Do not infer a universal effect from one source repository, one generation per method, or one judge pass.
